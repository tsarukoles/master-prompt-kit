# Changelog

## 0.2.0 — 2026-10-22 — expanded pilot

Rebuilt the discovery starter into a portable QA architecture and AI workflow library.

- Added QA blueprint, decision worksheets, test/data/flake strategy, and optional agent role cards with a primary independent verifier.
- Added workflows for case generation, implementation, verification, failure triage, reporting, and release decisions, with fictional new/existing-project examples and blind verifier challenges.
- Added Knowledge Vault templates, provenance/freshness rules, normalized database inventory and policy-gated PostgreSQL/SQL Server catalog-query illustrations.
- Added QA hook recommendations, documented event/bypass limits, a neutral tested edit-check signal, and assistant adapter guidance.
- Added tested environment resolver/eligibility/action guards, evidence/verdict schemas and consistency checks, integration contracts, starter files, and CI mapping.
- Added dependency-free validation and deterministic ZIP packaging with a per-file manifest. Curated ZIP/checksum are release assets; old archives are no longer duplicated on the main branch.

Use START-HERE.md with the target project. Select relevant modules, authorize a scoped change, then independently verify it. See VALIDATION.md for observed checks and remaining provider/field limits. This remains a prerelease pending full field validation and target-specific adapter trials.
