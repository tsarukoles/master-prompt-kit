# Optional project starter

Choose starter files only after discovery. [PROJECT-INSTRUCTIONS.md.template](PROJECT-INSTRUCTIONS.md.template) is a short neutral instruction skeleton. Adapt it into the instruction filename supported by the actual assistant after checking that product's rules. [ADOPTION-RECORD.md](ADOPTION-RECORD.md) records what was adopted and why. Nothing in this folder auto-installs a server, creates an agent, or enables a hook.

For an existing repository, merge the selected guidance into its current entry point and knowledge structure. Avoid competing instruction files. For a new repository, begin with one entry point, one small behavior test, and its environment/data contract. The [architecture guide](../architecture/AGENTS-AND-KNOWLEDGE.md) describes how to grow from there.

After adaptation, ask a fresh assistant session to find the project goal, correct test command, allowed target, evidence location, and stopping condition. That practical navigation check is more useful than merely verifying files exist.
